🌱 EcoPrompt Coach — Test Playground

Three mock chat interfaces that look and behave like the real thing — composer, streaming replies, the lot — so you can test the EcoPrompt Coach extension with real-world prompts without sending anything to an actual AI model.

1 · Install the extension (one minute)

  1. Clone the repo: git clone https://github.com/moseskolleh/promptcoach
  2. Open chrome://extensions in Chrome and enable Developer mode (top right)
  3. Click Load unpacked and select the apps/extension folder
  4. Come back here and open a chat below — a small eco-pill appears near the composer

Already using the extension on real sites? It works here too: this demo's address is in the extension's allowed sites, and each mock page tells the extension which model it simulates, so grades match the real service.

2 · Pick a chat to test in

NovaChat

ChatGPT-style: dark theme, contenteditable composer. Simulates GPT-5.

Clarion

Claude-style: warm cream, serif greeting, rich-text composer. Simulates Claude Sonnet 4.5.

Lumina

Gemini-style: Google light theme, plain textarea composer. Simulates Gemini 2.5 Flash.

3 · What to try

  • Grades react as you type. Every chat has an “Example prompts” drawer with real-world prompts. Click one and watch the pill's grade and energy line update live.
  • Output budgets pay off. Type “Explain how photosynthesis works”, then add “Answer in 50 words or less” — the estimate drops and the coach acknowledges the budget instead of nagging.
  • Courtesy costs tokens. The over-polite email example shows how many tokens the please-and-thank-you padding costs — open the pill's card to see the trim suggestion.
  • Some prompts shouldn't be prompts. Ask for tomorrow's weather or a 15% tip and the coach recommends a weather app or calculator instead. Ask for a poem about weather and it correctly stays quiet.
  • Model gaps are huge. Send the same prompt in NovaChat (GPT-5) and Lumina (Gemini Flash) and compare grades — then open the extension popup for the full model comparison and your recorded history.
  • Sends are recorded. Every message you send here lands in the extension popup's personal impact dashboard, just like on the real sites.
